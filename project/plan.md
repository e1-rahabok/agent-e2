## Mission
- Release 1.0 ([SCOPE-1](https://github.com/e1-rahabok/private-cloud-workspace/blob/main/spec/brief.md), SCOPE-6): a demo in the author's lab. Agent E2 runs Gemma 4 31B through Vercel AI Gateway (R-E2-001) for two callers, PCM and isvara.io. Its free-text answers are graded automatically (R-E2-005). Agent E2 is ready for release 1.0 when its answer set passes on the shipped settings and spending is projected within US$50 a month (plan milestone A6, ready for release 1.0; R-E2-006).
- The target after release 1.0, the on-premises deployment (parked, SCOPE-1): Agent E2, an expert system of agent, harness, knowledge base and an open-weight model, running locally (customer data stays on site) on enterprise GPU on premises (one GPU is an ideal, not a constraint; up to four large GPUs are acceptable). The benchmark is the proof that it works (MISSION.md).
- The benchmark's release gate belongs to the on-premises deployment on a local model (parked). Reference numbers for the author's release decision (Q-E2-130; [benchmark/design.md](https://github.com/e1-rahabok/agent-e2/blob/main/benchmark/design.md), section 7.5), Agent E2 as shipped (one pipeline, the expert-led agent of [harness/AGENT.md](https://github.com/e1-rahabok/agent-e2/blob/main/harness/AGENT.md)) on the local model: final score at least 85%; Level 400 at least 80%; confident-wrong at most 3%; no up-front misconception (the `## Misconceptions` lines marked `up_front`) stated as true; held-out set at most 11 points below the development set. The gap to the frontier model is an outcome, reported with its paired test, not a gate. Target 99%. Confirmed on the shipped configuration by the live test.
