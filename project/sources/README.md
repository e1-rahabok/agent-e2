# Sources

Source documents the knowledge is written from: the author's book, vendor PDFs. The author adds sources; Claude may edit them (author, 2026-11-14). Not indexed, not shipped, not read at run time.

Examples:
- Microsoft Word documents (.docx)
- draw.io / diagrams.net files
- PowerPoint decks
- PDFs
- Screenshots or exported images
- Any other primary source material

These files may cut across multiple VCF components (vSphere, NSX, vSAN, etc.), which is why this folder sits at the `knowledge/` level rather than under a specific component.

The structured knowledge under `vsphere/`, `nsx/`, etc. is derived from these raw materials.
