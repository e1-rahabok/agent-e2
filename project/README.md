# Project

How this repository is built and kept correct. Not indexed. The model reads `knowledge/`.

- `plan.md`: mission, milestones, what we are not doing, open work. Read first.
- `author-questions.md`: every open question, in two sections: Release 1.0 and Future release.
- `author-questions-resolved.md`: answered and done, kept as history.
- `terms.md`: one English word per concept for the repository's own parts.
- `tools/`: lint, link and renumber scripts; allowed tag values (`rules_check_values.yaml`).
- `archive/`: records no longer maintained: earlier reviews, the plan's decision logs, the benchmark results of the classic and agentic generation, the tool-loop agent's design and code, earlier designs, the old to-do list, legacy files.
- Design, architecture and knowledge rules: the root documents listed in [`README.md`](../README.md), section Documents.
