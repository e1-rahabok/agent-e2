# Project

How this repository is built and kept correct. Not indexed. The model reads `knowledge/`.

- `plan.md`: mission, milestones, decisions, what we are not doing, open work. Read first.
- `author-questions.md`: open questions for the author, with an index of resolved ones.
- `author-questions-resolved.md`: answered questions, kept with their answers.
- `terms.md`: one English word per concept for the repository's own parts.
- `tools/`: lint, link and renumber scripts; allowed tag values (`tags.yaml`).
- `archive/`: records no longer maintained: the reviews (2026-11-06, 2026-11-11, 2026-11-13), the plan's decisions before 2026-11-14, the benchmark results of the classic and agentic generation, the tool-loop agent's design and code, earlier designs, the old to-do list, legacy files.
- Design, architecture and knowledge rules: the root documents listed in [`README.md`](../README.md), section Documents.
