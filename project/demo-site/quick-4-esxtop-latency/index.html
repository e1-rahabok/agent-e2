Quick answer · host esx-04 · esxtop
esxtop disk device panel on host esx-04, one LUN: GAVG/cmd 5.4 ms, KAVG/cmd 4.6 ms, QAVG/cmd 4.5 ms, DAVG/cmd 0.8 ms. The storage team says the array is fine. One colleague adds KAVG and QAVG and says the host adds 9 ms. Another says every value is below 10 ms, so storage is healthy. Where does the time go, and is the array the problem?
Agent E2

Conclusion: the latency is in the ESXi host VMkernel queue, not in the array. The LUN is healthy from the device side.

Mechanism and reason

  • GAVG = KAVG + DAVG. vsphere/technology/storage/concepts/esxi-storage-latency-stack

GAVG 5.4 ms = KAVG 4.6 ms + DAVG 0.8 ms. The bulk is kernel, not device.

  • DAVG 0.8 ms is device/fibre time from HBA to array and back. It is low and consistent with the storage team saying the array is fine. vsphere/technology/storage/concepts/esxi-storage-latency-stack
  • KAVG 4.6 ms is time in the VMkernel. Flow test: ESXi Disk Kernel Latency KAVG > 0.5 ms means commands wait in the VMkernel, mostly in a queue: read QAVG and queue depths. vsphere/technology/storage/troubleshooting/host-storage-latency

QAVG 4.5 ms ≈ KAVG, so ~4.5 ms of the 5.4 ms GAVG is queue wait inside ESXi. QAVG is part of KAVG, not additive. Adding KAVG + QAVG = 9 ms is wrong.

  • “Below 10 ms = healthy” is a misconception. The Broadcom KB 344099 upper bound is not a health test. A KAVG of several ms more than triples GAVG behind a flash array with DAVG <1 ms, and means each command waits most of its time in a VMkernel queue. vsphere/technology/storage/concepts/esxi-storage-latency-stack

What to check next

  • Queue depths on the path: esxtop DQLEN, ACTV, QUED, LOAD, DSNRO per device; adapter queue AQLEN; per-VM virtual disk IOPS/latency and any IOPS limit. High QAVG with normal DAVG is VMkernel queueing from DQLEN/DSNRO saturation or a per-virtual-disk IOPS limit. vsphere/technology/storage/troubleshooting/host-storage-latency ; vsphere/technology/storage/concepts/esxi-storage-io-path
  • Read vs write split per adapter/path and 95th/99th percentile, not a single sample, to confirm the pattern is sustained.
