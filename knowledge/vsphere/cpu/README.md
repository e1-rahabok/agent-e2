# CPU

Deep knowledge about CPU virtualization and performance in vSphere.

## Folders

- `architecture/` — How CPU scheduling and virtualization actually work
- `resource-management/` — Shares, reservations, limits, ready time, co-stop, etc.
- `counters/host/` — Performance counters from the HostSystem perspective
- `counters/vm/` — Performance counters from the VirtualMachine perspective
- `interpretation/` — How to read groups of counters together to diagnose real problems

## Principle

Counters are a byproduct.  
True understanding comes from the architecture and resource management mechanisms.
