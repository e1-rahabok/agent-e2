# Foundations

Cross-cutting knowledge that shapes how we think about all metrics and performance in vSphere.

This layer sits above the individual resource areas (CPU, Memory, Storage, Network).

## Folders

- `metrics-philosophy/` — What metrics really are, nuances, naming problems, industry-wide issues
- `vm-vs-guest-os/` — The critical distinction between the virtual motherboard and the Guest OS
- `overhead-and-buffers/` — Overhead concepts and different types of buffers
- `observability-principles/` — Broader principles of good observability in a virtualized environment

Content here should help both humans and the AI develop the correct mental models before diving into specific counters.
